# فین‌مایند (FinMind)

تصمیم‌یار مالی هوشمند برای خانوار ایرانی، با حساب کاربری واقعی و چندکاربره. یک صفحه‌ی معرفی عمومی (`/`)، یک صفحه‌ی ورود/ثبت‌نام (`/login.html`)، و یک پنل کاربری خصوصی (`/panel/`) که هر دسته از قابلیت‌ها (تحلیل دارایی‌ها، ریسک، نقدینگی، اهداف مالی، شبیه‌ساز سناریو، دستیار قبل از تصمیم، هشدارهای رفتاری) صفحه‌ی مخصوص خودش را دارد؛ گفتگوی زنده با دستیار مالی هم یک صفحه‌ی کاملاً جداست. محاسبات اصلی (بهینه‌سازی پرتفوی، شبیه‌سازی سناریو، دسته‌بندی نقدینگی، قیمت‌گذاری آنی طلا/ارز/رمزارز) با موتورهای ریاضی/آماری قطعی انجام می‌شوند؛ یک مدل زبانی (gpt-4.1-mini از طریق Parspack) فقط این اعداد را با کانتکست کامل پروفایل کاربر به فارسی توضیح می‌دهد و در چت به‌صورت زنده (کلمه‌به‌کلمه) استریم می‌شود.

## حساب کاربری

هر کاربر با ایمیل/رمز عبور حساب می‌سازد (`auth.js` — رمز با `scrypt` هش می‌شود، نشست با کوکی امضاشده‌ی HttpOnly مدیریت می‌شود، بدون نیاز به دیتابیس یا سرویس خارجی). داده‌ی هر کاربر (پروفایل، دارایی‌ها، مدل ریسک رفتاری) کاملاً جدا و زیر `data/users/<userId>/` ذخیره می‌شود؛ فقط دیتاست تجمیعیِ فاز ۵ (`dataAsset.js`) عمداً بین همه‌ی کاربران مشترک است تا با رشد تعداد کاربران واقعاً ارزشمند شود.

## ورود اطلاعات

کاربر فقط یک‌بار، در یک مسیر راهنما‌شده ۵ مرحله‌ای (اطلاعات شخصی → ریسک و تجربه → درآمد/هزینه/بدهی → دارایی‌ها → هدف اصلی)، اطلاعاتش را وارد می‌کند. بعد از پایان مسیر (`onboarded: true` در پروفایل)، بقیه‌ی ویجت‌ها آزاد می‌شوند و کارت پروفایل به یک خلاصه‌ی جمع‌وجور («۲۹ ساله — مرد — ریسک‌پذیری ۶/۱۰ — ۴ دارایی ثبت‌شده») جمع می‌شود؛ کاربر دیگر لازم نیست هر بار همان داده‌های عددی را دوباره وارد کند، فقط در صورت نیاز دکمه‌ی «ویرایش اطلاعات» را می‌زند. فیلدهای اضافه‌شده برای شخصی‌سازی بهتر پیشنهادها: نوع شغل/درآمد، وضعیت مسکن، بدهی/اقساط فعلی، سطح تجربه‌ی سرمایه‌گذاری، واکنش خوداظهاری به افت ۲۰٪ ارزش دارایی‌ها (که یک‌بار به‌عنوان seed اولیه‌ی مدل ریسک رفتاری فاز ۴ هم استفاده می‌شود)، و مهم‌ترین هدف مالی زندگی به‌صورت متن آزاد.

### دستیار صوتی

به‌جای تایپ، کاربر می‌تواند دکمه‌ی ضبط را بزند و آزادانه درباره‌ی خودش حرف بزند. صدا در مرورگر ضبط می‌شود (`MediaRecorder`)، به سرور فرستاده می‌شود، با مدل واقعی `gpt-4o-transcribe` (همان provider/کلید LLM اصلی، endpoint `/audio/transcriptions`) به متن فارسی تبدیل می‌شود، و سپس مدل زبانی فقط همان چیزی را که واقعاً گفته شده از متن استخراج می‌کند (`promptVoiceExtract` در `prompts.js`) — نه حدس یا تولید داده‌ی جدید. هر آیتمی از چک‌لیست ۱۴تایی که در گفتار کاربر پیدا شود بلافاصله تیک می‌خورد و مقدار مستقیماً در فیلدهای فرم (همان فرم مسیر تایپی) پر می‌شود؛ کاربر می‌تواند چندبار ضبط کند تا موارد باقی‌مانده را هم بگوید، سپس به مرور نهایی در مسیر مرحله‌ای برود.

## اجرا

```bash
cd finmind
npm install
cp .env.example .env   # سپس FINMIND_API_KEY را با کلید واقعی پر کنید
npm start
```

سپس مرورگر را روی `http://localhost:4173` باز کنید.

## ساختار

- `server.js` — سرور Express و روت‌های API (همه به‌جز `/api/auth/*` و `/api/live-rates` پشت `requireAuth` هستند)
- `auth.js` — ثبت‌نام/ورود/نشست کاربر (هش رمز با scrypt، کوکی امضاشده با HMAC)
- `llm.js` — فراخوانی Responses API (معمولی و استریم) و پارس خروجی JSON
- `prompts.js` — پرامپت‌های فارسی هر بخش (فقط توضیح اعداد محاسبه‌شده، نه منبع محاسبه)
- `optimizer.js` — بهینه‌سازی پرتفوی با Quadratic Programming؛ نوسان و همبستگی دسته‌های قیمت‌دار از داده‌ی واقعی ۳ ساله می‌آید، بازده مورد انتظار همچنان فرض است
- `portfolioRisk.js` — موتور پراکندگی و ریسک (پورت JS از `calculator.py` پایپ‌لاین workflow): HHI، تعداد مؤثر، امتیاز تنوع، نوسان، بیشینه ریزش، CVaR، بتا، سهم ریسک هر کلاس
- `marketData.js` — بارگذاری بسته‌ی داده‌ی بازار و محاسبه‌ی نوسان/همبستگی دسته‌ها
- `riskPresenter.js` — تبدیل خروجی موتور ریسک به JSON ویجت‌ها و بلوک متنی پرامپت (بدون محاسبه‌ی جدید)
- `marketdata/market_pack.json` — ۱۵۶ هفته داده‌ی واقعی بازار ایران (خروجی منجمدشده‌ی پایپ‌لاین workflow)
- `tools/export_market_pack.py` — ساخت دوباره‌ی بسته‌ی داده: `PYTHONUTF8=1 python tools/export_market_pack.py --workflow <مسیر workflow>`
- `tools/verify_risk_engine.mjs` — تست رگرسیون: خروجی موتور JS باید با خروجی Python (`tools/risk_engine_reference.json`) یکی باشد؛ اجرا: `node tools/verify_risk_engine.mjs`
- `monteCarlo.js` — شبیه‌سازی سناریو با نمونه‌گیری از نرمال چندمتغیره شرطی
- `liquidityEngine.js` — دسته‌بندی قطعی نقدشوندگی هر دارایی
- `marketFeed.js` — نرخ آنی دلار/تومان و طلا از یک API واقعی و رایگان
- `assetPricing.js` — تبدیل گرم طلا / سکه / تعداد ارز به تومان با نرخ آنی
- `public/assetCatalog.js` — منبع واحد انواع دارایی (نوع طلا/سکه/صندوق/اوراق/خودرو، ارزها و رمزارزها) که هم فرم پروفایل هم موتورها از آن می‌خوانند
- `behaviorStore.js` — یادگیری ریسک‌پذیری از رفتار واقعی هر کاربر (per-user)
- `dataAsset.js` — لاگ تجمیعی تعاملات همه‌ی کاربران (فاز ۵)
- `store.js` — ذخیره‌سازی پروفایل هر کاربر در `data/users/<userId>/profile.json` (در گیت نیست)
- `public/` — صفحه‌ی معرفی (`index.html`)، ورود/ثبت‌نام (`login.html`)، هلپرهای مشترک فرانت‌اند (`common.js`)
- `public/panel/` — پنل کاربری: هر صفحه (dashboard, profile, assets, risk, liquidity, goals, scenario, decision, alerts, chat) یک HTML + JS مستقل دارد؛ `panel-shell.js` نوار کناری/بالایی مشترک را رندر می‌کند و ورود کاربر را چک می‌کند

جزئیات معماری و نقشه‌راه توسعه در [ROADMAP.md](./ROADMAP.md).

## نکته امنیتی

کلید API در `.env` نگه‌داری می‌شود و در گیت commit نمی‌شود. برای اجرا روی سیستم دیگر، `.env` را دستی بسازید.

## مدل نوسان آینده (ML)

`pipeline/10_train_vol_model.py` (در پوشه‌ی workflow) نوسان ۲۶ و ۵۲ هفته‌ی آینده‌ی سبد را با LightGBM (تصحیح روی خروجی FHS) پیش‌بینی می‌کند و با همان آزمون سخت‌گیرانه‌ی سایر مدل‌ها (برد روی val و test، حداقل ۲٪ مهارت روی test، سوگیری کم، بوت‌استرپ ماهانه ≥ ۰٫۷۵) سنجیده می‌شود. فقط اگر قبول شود، `tools/export_market_pack.py` آن را به `marketdata/stack_models/vol_*.json` می‌برد و `stackForward.js` در تحلیل ریسک نشانش می‌دهد؛ وگرنه هیچ عددی از آن نمایش داده نمی‌شود. آخرین اجرا (۴ مهر ۱۴۰۵): روی val حدود ۳۰٪ بهتر از مرجع بود ولی روی test فقط ۰٫۷٪ (۲۶ هفته) و ۳٫۴٪ (۵۲ هفته، بوت‌استرپ ۰٫۶۱) → قبول نشد و ارائه نمی‌شود.
