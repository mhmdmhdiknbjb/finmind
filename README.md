# فین‌مایند (FinMind)

پروتوتایپ یک تصمیم‌یار مالی هوشمند برای خانوار ایرانی. یک پنل تک‌صفحه‌ای شامل ۸ ویجت (چت، تحلیل دارایی‌ها، ریسک، نقدینگی، اهداف مالی، شبیه‌ساز سناریو، دستیار قبل از تصمیم، هشدار رفتار هیجانی) که همگی از یک مدل زبانی (gpt-5-mini از طریق Parspack) با کانتکست کامل پروفایل کاربر تغذیه می‌شوند.

## اجرا

```bash
cd finmind
npm install
cp .env.example .env   # سپس FINMIND_API_KEY را با کلید واقعی پر کنید
npm start
```

سپس مرورگر را روی `http://localhost:4173` باز کنید.

## ساختار

- `server.js` — سرور Express و روت‌های API
- `llm.js` — فراخوانی Responses API و پارس خروجی JSON
- `prompts.js` — پرامپت‌های فارسی هر ویجت (مغز تحلیلی سیستم)
- `store.js` — ذخیره‌سازی پروفایل کاربر در `data/profile.json` (در گیت نیست)
- `public/` — فرانت‌اند (HTML/CSS/JS خام + Chart.js لوکال)

## نکته امنیتی

کلید API در `.env` نگه‌داری می‌شود و در گیت commit نمی‌شود. برای اجرا روی سیستم دیگر، `.env` را دستی بسازید.

## نقشه‌راه

نسخه‌ی فعلی یک LLM-wrapper است (هر تحلیل از طریق پرامپت انجام می‌شود). مسیر تبدیل شدن به یک موتور AI/ML واقعی (بهینه‌سازی پرتفوی، شبیه‌سازی مونت‌کارلو، پیش‌بینی سری زمانی، مدل ریسک رفتاری، دارایی داده‌ای اختصاصی) در [ROADMAP.md](./ROADMAP.md) مستند شده است.
