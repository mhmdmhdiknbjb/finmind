# فین‌مایند (FinMind)

پروتوتایپ یک تصمیم‌یار مالی هوشمند برای خانوار ایرانی. یک پنل تک‌صفحه‌ای شامل ۸ ویجت (چت، تحلیل دارایی‌ها، ریسک، نقدینگی، اهداف مالی، شبیه‌ساز سناریو، دستیار قبل از تصمیم، هشدار رفتار هیجانی). محاسبات اصلی (بهینه‌سازی پرتفوی، شبیه‌سازی سناریو، دسته‌بندی نقدینگی، قیمت‌گذاری آنی طلا/ارز) با موتورهای ریاضی/آماری قطعی انجام می‌شوند؛ یک مدل زبانی (gpt-4o-mini از طریق Parspack) فقط این اعداد را با کانتکست کامل پروفایل کاربر به فارسی توضیح می‌دهد.

## اجرا

```bash
cd finmind
npm install
cp .env.example .env   # سپس FINMIND_API_KEY را با کلید واقعی پر کنید
npm start
```

سپس مرورگر را روی `http://localhost:4173` باز کنید.

## ساختار

- `server.js` — سرور Express و روت‌های API
- `llm.js` — فراخوانی Responses API و پارس خروجی JSON
- `prompts.js` — پرامپت‌های فارسی هر ویجت (فقط توضیح اعداد محاسبه‌شده، نه منبع محاسبه)
- `optimizer.js` — بهینه‌سازی پرتفوی با Quadratic Programming
- `monteCarlo.js` — شبیه‌سازی سناریو با نمونه‌گیری از نرمال چندمتغیره شرطی
- `liquidityEngine.js` — دسته‌بندی قطعی نقدشوندگی هر دارایی
- `marketFeed.js` — نرخ آنی دلار/تومان و طلا از یک API واقعی و رایگان
- `assetPricing.js` — تبدیل گرم طلا / تعداد ارز به تومان با نرخ آنی
- `behaviorStore.js` — یادگیری ریسک‌پذیری از رفتار واقعی کاربر
- `dataAsset.js` — لاگ تجمیعی تعاملات کاربر
- `store.js` — ذخیره‌سازی پروفایل کاربر در `data/profile.json` (در گیت نیست)
- `public/` — فرانت‌اند (HTML/CSS/JS خام + Chart.js لوکال)

جزئیات معماری و نقشه‌راه توسعه در [ROADMAP.md](./ROADMAP.md).

## نکته امنیتی

کلید API در `.env` نگه‌داری می‌شود و در گیت commit نمی‌شود. برای اجرا روی سیستم دیگر، `.env` را دستی بسازید.
